# 🏦 Bank Loan Approval Prediction

Complete Week 4 classification project.

## Assignment alignment
The brief specifies:
- Kaggle – Loan Prediction Dataset
- Clean categorical data such as Gender, Marital Status and Income
- Train Random Forest / XGBoost
- Evaluate with a Confusion Matrix
- Predict if a loan can be approved

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The included CSV is a runnable demo dataset following the common Kaggle Loan Prediction schema. You can upload a compatible Kaggle CSV from the sidebar.
